किसी भी AI से कॉपी करके एक साथ पेस्ट करें

ChatGPT, Gemini, Claude या किसी भी AI के सवाल-जवाब पूरे एक साथ नीचे पेस्ट करें। पहचानने के बाद आप जाँचकर सेव कर सकते हैं।

कौन-से फ़ॉर्मेट पहचाने जाते हैं?
  1. Q: ... A: ... या प्रश्न: ... उत्तर: ... या सवाल: ... जवाब: ... (नंबर के साथ भी: Q1., Q2.)
  2. 1. सवाल और उसके नीचे जवाब की लाइनें
  3. खाली लाइन से अलग किए गए ब्लॉक: पहली लाइन सवाल, बाकी जवाब
  4. JSON: [{"question":"...","answer":"..."}]

नई API बनाएँ

API आपके सभी सेव सवाल-जवाब का एक पढ़ने-भर का स्नैपशॉट है। हर वेबसाइट या व्यक्ति के लिए अलग API बनाएँ, ताकि ज़रूरत पड़ने पर सिर्फ़ उसी को बंद कर सकें।

अपनी वेबसाइट में HTML कैसे जोड़ें?
  1. नीचे अपनी API के कार्ड पर कोड देखें दबाएँ।
  2. HTML एम्बेड कोड के आगे कॉपी दबाएँ।
  3. अपनी वेबसाइट की HTML फ़ाइल खोलें और कोड को </body> से ठीक ऊपर पेस्ट करें। WordPress में "Custom HTML" ब्लॉक, Blogger में "HTML/JavaScript" गैजेट, Wix में "Embed Code" में पेस्ट करें।
  4. पेज के <head> में <meta charset="UTF-8"> होना चाहिए, वरना हिंदी बिगड़ सकती है।
  5. सवाल-जवाब बदलने पर API कार्ड पर अपडेट करें दबाएँ। वेबसाइट में दोबारा कोड डालने की ज़रूरत नहीं।

AI दिमाग (Ollama)

चालू होने पर यूज़र के सवाल पर AI आपके सेव सवाल-जवाब पढ़कर सोचता है और अपने शब्दों में जवाब देता है। जो बात सेव जानकारी में नहीं है, वह नहीं बताता और सवाल "बिना जवाब" में आ जाता है।

Ollama को सबके लिए कैसे चलाएँ?
  1. Ollama इंस्टॉल करें (ollama.com) और मॉडल डाउनलोड करें: 
    ollama pull llama3.2
    हिंदी के लिए qwen2.5:7b भी अच्छा है।
  2. ब्राउज़र को अनुमति देने के लिए Windows में कमांड प्रॉम्प्ट में यह चलाएँ, फिर Ollama बंद करके दोबारा चालू करें: 
    setx OLLAMA_ORIGINS "*"
    Mac/Linux में: OLLAMA_ORIGINS="*" ollama serve
  3. cloudflared इंस्टॉल करके सुरंग (tunnel) चलाएँ: 
    cloudflared tunnel --url http://localhost:11434 --http-host-header="localhost:11434"
  4. जो https://....trycloudflare.com लिंक दिखे, उसे ऊपर URL में डालें, सेव करें और जाँचें दबाएँ।
  5. यह लिंक हर बार tunnel दोबारा चलाने पर बदल जाता है, तब नया लिंक यहाँ डालना होगा। पक्का लिंक चाहिए तो Cloudflare का नामित tunnel बनाएँ।

ध्यान रखें: कंप्यूटर और tunnel चालू रहने तक ही AI चलेगा। बंद होने पर ऐप सेव जवाब से काम करता रहेगा। यह URL जिसके पास होगा वह आपके कंप्यूटर का AI इस्तेमाल कर सकता है, इसलिए इसे सार्वजनिक न करें।
